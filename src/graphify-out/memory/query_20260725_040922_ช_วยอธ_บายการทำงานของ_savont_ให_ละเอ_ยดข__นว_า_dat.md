# Q: ช่วยอธิบายการทำงานของ savont ให้ละเอียดขึ้นว่า data process ไปยังไง จนได้ polished consensus

## Answer

Expanded from original query via graph vocab: [read, kmer, snpmer, marker, cluster, consensus, alignment, homopolymer, pileup, quality, polish, merge]. Savont scans reads to count split k-mers and identify population-supported SNPmers, converts filtered reads into TwinRead objects containing syncmer/minimizer, SNPmer, quality and LSH representations, performs greedy 0.95 k-mer similarity clustering followed by zero-SNPmer-mismatch subclustering and iterative consensus-marker reclustering, builds quality-weighted SPOA consensus from at most 75 high-quality reads per cluster, remaps up to 250 reads to form quality-aware pileups, estimates empirical error rates, flags or masks low-confidence sites and removes low-quality consensus clusters, then removes lower-depth consensus sequences whose internal minimizer set is fully contained in a consensus more than twice as deep. The survivors are written as polished_consensuses.fasta. This file is pre-alignment-merge, pre-chimera-filter and pre-EM, so it is not final_asvs.fasta.
